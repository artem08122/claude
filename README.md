# claude

## Пещера Платона — 3D-анимация

`plato-cave/index.html` — трёхмерная анимация аллегории пещеры из седьмой книги «Государства» Платона (514a–517c). Один HTML-файл, Three.js 0.160 подключается с jsDelivr, сборка не нужна.

Семь сцен, около двух минут:

| Глава | Стефан | Что происходит |
| --- | --- | --- |
| I. Тени | 514a | Узники в оковах смотрят на стену; огонь за оградой отбрасывает на неё тени статуй и утвари |
| II. Огонь | 515c | Одного освобождают: он встаёт, оборачивается, огонь слепит; вид его глазами |
| III. Подъём | 515e | Путь вверх по крутому ходу к выходу, засвет |
| IV. Отражения | 516a | Снаружи: сначала тени на траве, потом отражения в пруду, вещи, ночное небо |
| V. Солнце | 516b | Рассвет, силуэт на фоне солнца |
| VI. Возвращение | 516e | Спуск обратно во тьму, узники смеются над ним |
| VII. Смысл | 517b | Толкование самого Платона, общий план пещеры |

Как открыть: запустите локальный сервер в корне репозитория (`npx serve .` или `python3 -m http.server`) и откройте `/plato-cave/`. Нужен браузер с WebGL.

Управление: пробел — пауза, стрелки — соседние главы, клик по шкале внизу — переход к главе. Звук синтезируется в браузере (огонь, гул, ветер) и включается кнопкой. Ссылка с якорем главы, например `#solntse`, открывает анимацию с этой главы.
